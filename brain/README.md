## Conventions
- Every file carries `*vX.Y · updated YYYY-MM-DD*` under its title. Minor edits bump Y; rewrites bump X.
- Filenames start with their layer (`L1-`, `L2-`, `L3-`).
- When a file outgrows itself, rebuild it — that's what the version numbers are for.
- Anything marked **(inferred)** came from JP's published writing, not from JP directly. Confirm or correct it, then drop the tag.
